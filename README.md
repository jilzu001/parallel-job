# 평행세계 직업사무소 · 시제품

https://jilzu001.github.io/parallel-job/

12문항을 통해 익숙한 장르 속 뜻밖의 직업을 찾는 정적 웹 콘텐츠. 36개 세계 × 12개 역할 = 432개 직업 후보. 레어리티나 결제·전투 기능 없음.

- `data/questions.json`: 질문과 역할/장소 가중치
- `data/worlds.json`: 세계별 직업과 배경
- `data/roles.json`: 역할별 능력·약점·기본 능력치
- `build_data.py`: 원본 콘텐츠를 JSON으로 변환. JSON 직접 편집 시 재실행하면 덮어써짐.
- `pixel.js`: 배경·몸·머리·의상·도구·장식의 공통 좌표를 이용한 원본 도트 레이어 조합. 카드별 완성 이미지를 저장하지 않음.
- `app.js`: 매칭·저장·퀴즈 UI. 역할 최고점, 장소 선호 점수, 답변 해시로 동점 결정. 능력치도 답변 기반이며 무작위 성별과 외형은 무관.
- `blog.html`: 티스토리 HTML 모드용 소개글과 iframe.

성별은 결과 생성 시 50:50 무작위로 정하는 허구의 캐릭터 설정. 방문자가 접속한 브라우저 저장소에 최근 카드 최대 100개 저장. iframe의 저장소 사용은 브라우저의 개인정보 설정에 따라 제한될 수 있으며 제한 시 현재 화면에서 사용 가능. 서버에 개인정보·답변을 보내지 않음.

시제품은 역할별 공유 풀이와 세계별 직업명을 조합한다. 432개 장편 이야기가 각각 작성된 버전은 아니다. 캐릭터 그림 저장은 도트 장면만 저장하며 전체 카드 캡처 기능은 포함하지 않는다.

검증: `python -m http.server 8781` 실행 후 `node test.cjs`. GitHub Pages 배포 후 `TEST_URL` 환경변수로 동일 테스트 실행 가능.
