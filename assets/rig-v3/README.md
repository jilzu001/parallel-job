# 고정 등록 좌표 스프라이트 V3

새 검수 화면: https://jilzu001.github.io/parallel-job/composition-lab.html

83개 64×80 PNG 셀(장비 없음 셀 포함)을 한 시트로 저장한다. 실행 시 원본 셀을 자르고 64×80 층의 (0,0)에 그대로 그린다. 개별 부품의 회전/확대/축소가 없다. 고전 스프라이트 시트, 등록점과 팔레트 제한 방식을 브라우저 Canvas로 구현했다. 고전 하드웨어 ROM 포맷을 에뮬레이션한 것은 아니다.

구성: 얼굴 8(남성/여성×피부톤4), 헤어/모자20, 의상24, 도구24, 등 장비3(없음 포함), 앞 손4. 얼굴·헤어·옷·손은 작은 공통 픽셀 좌표에 그린 코드 원본 `sprite-rig.js`에서 작성한다. 그림 세부는 사용자 예시의 수준에 아직 못 미치는 구조 검증용 아트다. 기존 AI 부품 V1을 확대·축소해 맞춘 버전이 아니다.

기준점: 목(33,34), 손(45,48), 발(32,72). 셀 밖 그리기 금지. 손은 도구 앞에 합성. 긴 헤어는 의상 뒤에 합성하며 헬멧/모자 후보는 의상별 제한. 직업별 도구 후보와 세계별 의상 후보는 `data/visual-rules.json`에서 관리한다. 세계관 전용 후보, 공통 역할 후보, 의상 호환 헤어를 선택한 뒤 저장된 seed로 결정한다. 배경은 대부분 세계관 공유 장소이며 일부 세계는 직업별 공통 서고/생활 공간으로 전환한다.

PNG는 캐릭터 부품만 약35KB. 배경은 기존 생성 배경 V1을 장면 256×192 규격으로 준비해 묶은 뒤 lossless WebP로 압축했다. PNG와 WebP 픽셀 바이트가 동일한 것을 확인했으며 약1MB. 실행 시 배경 원본 시트에서 256×192 장면을 꺼낸다. 기존 대형 V1 아틀라스는 검수와 제작 입력용이고 이 화면 실행 시 내려받지 않는다.

제작: 로컬 서버8781에서 `node test-rig.cjs`는 `?author=1` 원본 도안을 이용해 PNG를 다시 만든다. `RIG_URL`을 설정하면 완성 시트를 소비하는 경로만 검증하고 파일을 덮어쓰지 않는다. 배경 PNG 재생성 시 WebP도 다시 무손실 변환해야 한다.

검증: 36세계×12역할×2성별=864개 조합, 동일 seed 외형 유지, 모든 부품64×80, 선택 컨트롤과 3개 화면 폭, 오류 없음. 이 검사는 시각적 완성도가 사용자 예시와 같다는 뜻은 아니다. 본 앱 그래픽은 아직 교체하지 않았으며 별도 페이지로 검수한다.
