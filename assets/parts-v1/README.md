# 부품 검수 초안 V1

기본 7종류와 카드 UI 장식, 총 132개 후보를 8개 PNG 시트로 보관한다. `manifest.json`의 행/열과 번호는 검수용 구역이다. 132개가 전부 실제 조합 테스트를 통과한 최종 부품이라는 뜻은 아니다.

생성 방법: 내장 image_gen 도구. 완료 이미지 생성이 아닌 재사용 이미지 재료 생성. 최신 검수 요청에 따라 앱 소비 코드는 연결하지 않았다.

프롬프트 세트의 공통 요구: 고전 16비트 RPG, 선명한 도트 외곽, 제한된 색과 2~3단계 명암, 동일한 3/4 시점, 글자/라벨 없음, 배경 외 모든 시트는 alpha 투명. 분류별 지시: body는 남/여 × 피부톤 4종의 무모 기본형과 회색 기본복; heads는 10개 헤어와 10개 모자/헬멧; clothes는 머리 없는 24개 의상; tools는 24개 손 도구; back은 16개 등/허리 장비; effects는 16개 독립 효과; backgrounds는 12개 장소의 4×3 시트; ui는 4모서리와 구분선/문장/기능아이콘 12종.

적용 전 필요: 개별 실루엣의 영역 추출, 몸·의상·머리의 공통 기준점 보정, 앞/뒤 레이어 구분, 긴 머리와 망토 겹침 점검, 의상에 그려진 손·피부와 기본 몸 피부톤 일치 처리. 현재 생성된 의상은 일부 손/피부가 포함되어 있으므로 모든 피부톤과 바로 겹쳐 쓸 수 없다. 그림 검수와 조합 검증을 별도로 진행한다.
