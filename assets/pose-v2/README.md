# 고정 자세 조합 예시 V2

`assembly-proof.html`에서 실제 Canvas 합성. 배경 1개, 몸 1개, 헤어 2종, 의상 2종, 도구 2종, 앞 손 레이어 1개. 결과별 완성 이미지는 사용하지 않는다. 원본 PNG는 image_gen 내장 도구로 제작했으며, 생성 시트의 등록 위치가 완전히 일정하지 않아 코드에서 소스 영역과 공통 목적 좌표를 명시해 보정했다.

프롬프트: 사용자 카드의 작은 객잔 캐릭터 자세와 단순 고전 RPG 도트를 기준으로 한다. 배경은 인물과 들고 있는 도구를 제거한 객잔 한 장. 부품 시트는 기본 몸, 상투, 짧은 머리, 청록 도포, 갈색 여행복, 주전자, 장부, 앞 손을 4×2 alpha 투명 시트로 생성. 모든 파트에서 머리/몸/손 기준점 고정을 요청했다. 도구는 화면 오른쪽 손에 잡히도록 하고, 손을 도구보다 나중에 그린다.

검증: 2×2×2=8조합 렌더와 선택 컨트롤 동작, 실제 스크린샷의 자세/손 위치를 확인. 이 소수 재료 세트만 검증한 것이며 전체 132개 재료의 호환성이 검증됐다는 의미는 아니다. 남성·여성 확장과 다른 배경은 다음 제작 단계. 본 앱에는 연결하지 않고 검수 페이지로 제공한다.
